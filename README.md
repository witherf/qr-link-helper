# 二维码转链接（QR → Link）

一个 Chrome 浏览器扩展：识别网页图片、截图、粘贴图片里的二维码，提取出**可复制的链接**。

解决的问题：在微信里截图识别二维码时，经常被强行跳转到小程序（比如百度网盘链接会跳网盘小程序）。本扩展直接把二维码内容解码出来给你复制，**全程本地解码、不联网、不跳小程序**。

## 功能

- **右键识别**：在任意图片上右键 →「识别图片中的二维码」
- **悬停识别**：鼠标移到图片上，右上角出现「▣ 识码」按钮，点击即出结果
- **自动识别**：页面打开后自动扫描方形图片（二维码基本都是正方形，不会误扫普通图片），识别到的图片标绿框，工具栏图标显示角标计数
- **粘贴识别**：在任意网页按 `Ctrl+V` 粘贴截图，直接识别剪贴板里的二维码
- **弹窗识别**：点扩展图标，可拖入 / 选择图片识别，还能查看「本页识别到的所有二维码」列表
- **一键复制**：识别成功自动复制到剪贴板；面板里可「用浏览器打开」（走系统浏览器，不经过微信内置浏览器）
- **可设置**：悬停按钮 / 自动扫描 / 粘贴识别 / 自动复制，四项均可在弹窗里开关

## 安装（开发者模式加载）

1. 下载本仓库（`Code` → `Download ZIP`，或 `git clone`）并解压
2. 打开 Chrome，地址栏输入 `chrome://extensions`
3. 打开右上角**开发者模式**
4. 点**加载已解压的扩展程序**，选择本文件夹（含 `manifest.json` 的那层）
5. 建议把扩展固定到工具栏

## 技术说明

- Manifest V3，纯前端实现，无任何网络请求上传图片
- 解码核心为 [jsQR](https://github.com/cozmo/jsQR)（MIT License，已内置 `vendor_jsQR.js`，离线可用）
- 解码增强：多档缩放重试 + 颜色反转重试，支持反色二维码、小尺寸二维码
- 跨域图片（canvas 被污染时）由后台转为 base64 后再解码，兼容多数防盗链图片
- 界面全部使用 Shadow DOM，不污染页面样式

## 隐私

所有解码均在本地完成，图片不会上传到任何服务器；扩展仅在你主动触发识别时读取图片内容，不收集浏览记录。

## 目录结构

```
qr-link-helper/
├── manifest.json      # 扩展清单（MV3）
├── background.js      # 右键菜单、跨域图片抓取、角标
├── content.js         # 悬停按钮、结果面板、自动扫描、粘贴识别
├── decoder.js         # 共用解码逻辑（多档缩放 + 反色重试）
├── vendor_jsQR.js     # jsQR 1.4.0（MIT）
├── popup.html/css/js  # 弹窗界面
├── icons/             # 扩展图标
└── demo/              # 本地演示页（装好后打开即可测试）
```
